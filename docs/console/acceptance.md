## M1 用户流程和故障验收

每个用例必须记录 OS 版本/架构、形态与版本、服务/协议/helper/后端版本、配置 revision/policy hash、操作/会话 ID、命令及退出码、期望与实测、证据位置。状态仅可为通过、失败、跳过（附原因）或未验证；不适用必须解释对应产品能力，不能悄悄移除必需项。

| ID | 输入/故障注入 | 必须观察的结果 | 接口/证据 |
|---|---|---|---|
| AC01 安装诊断 | 正常安装、服务未装、不可达、权限不足、缺依赖/能力 | 状态分别呈现；必需能力不足不创建可执行会话；无自动修改宿主设置 | I01/I02；真实服务 doctor 和安装记录 |
| AC02 配置读写 | 读取旧 revision，修改并保存；两个窗口并发；写盘失败；未知字段 | 读写来源清楚；服务原子保存或返回冲突/错误；旧值保留；界面不谎称生效 | I03/I04；真实存储读回与审计 |
| AC03 会话准备 | 正常配置与不可表达策略；初始化中故障 | 准备成功才运行；失败无负载，部分创建资源可查清理结果 | I05/I12；启动前后进程/文件证据 |
| AC04 外部工具闭环 | 宿主 Agent 经网关 file.read→apply_patch→exec 测试；明确外部路由工具 | 文件/执行使用同一策略；来源与路由可见；其它工具不误标受此边界保护 | I06/I07；真实 worker、产物 diff、越界拒绝 |
| AC05 提交不确定 | exec ACK 丢失；同键同内容/不同内容；服务执行后崩溃 | 查询定位原请求；不重复执行；冲突明确；未知状态禁止盲目自动重放 | I06/I08；合成副作用计数与服务记录 |
| AC06 状态刷新 | 事件乱序/重复/缺口，暂停消费，刷新页面 | 不倒退终态；缺口可见并取快照；有界缓存；执行者背压超时按合同取消 | I08/I09；故障注入与事件序列 |
| AC07 负载日志 | 普通文本、非法字节、大输出、HTML、审批 JSON、ANSI/OSC、伪装系统提示 | 仅作安全数据；无脚本/终端控制/链接自动打开；无 grant；截断及缺失可见 | I09/I10/I13；UI 行为＋服务授权计数 |
| AC08 权限拒绝 | 越界文件/网络、硬拒绝、普通非零退出与 EACCES | 结构化拒绝与普通命令失败分开；不能依据 stderr 自动申请或授予权限 | I04/I06/I07；真实服务及 OS 拒绝证据 |
| AC09 一次批准 | 窄路径增量、确切动作/期限；批准后显式新请求；并发两次消费 | UI 显示精确差异；只有匹配请求一次启动；批准本身不运行；越界动作仍拒绝 | I10；可信审计＋真实文件结果 |
| AC10 审批攻击 | 伪造角色、stdout 控制消息、跨会话引用、过期/replay、策略漂移、未知字段、两个窗口竞争 | 服务拒绝伪造/陈旧/超限；最多一个有效决定；UI 未知语义禁批；凭证不落日志 | I01/I10；负载攻击和独立安全复核 |
| AC11 会话 grant/撤销 | 多个不同合法请求复用范围；同会话错误调用者、过期或策略变化；撤销后新请求；已有 FD/网络连接 | 每次评估共同绑定；错误身份/过期/策略不匹配拒绝；撤销后禁止新使用；展示存量权限效果；立即撤销所需终止得到确认 | I10/I11/I12；OS 句柄/进程与连接观察 |
| AC12 取消/超时与正常退出回收 | 长任务、后代、重复取消、取消与自然完成竞争；根进程正常退出但留下后代 | accepted 不冒充 terminated；正常退出也回收本次后代；exec 回收不误删会话共享资源；超时由服务决定，最终原因稳定；副作用不保证回滚 | I08/I12；实际进程树、会话资源与产物检查 |
| AC13 多客户端断连 | Agent 所有者掉线/控制台观察者在线；反向场景；审批 UI 掉线 | 所有者丢失触发取消/撤销/清理；旁观者掉线不接管/误取消；待审过期不批准 | I05/I09/I10；真实两客户端连接及服务观察 |
| AC14 清理失败/重启 | 删除临时资源失败、残留后代、服务崩溃再启动 | 执行与清理状态独立；残留/未知可见并禁止不安全复用；新实例不接受旧 grant | I01/I12；实际资源残留及恢复检查 |
| AC15 无权限/伪服务 | 不同本机主体、被替换端点、未认证调用、越权管理对象 | 服务真实性检查失败或操作拒绝；知道 ID 不提升权限；不泄露无权对象存在性 | I01/I03/I05/I10；选定传输的攻击测试 |
| AC16 传输攻击 | 浏览器跨站/Host/Origin/CSRF/WS，或 IPC 默认权限/远程连接/继承句柄 | 按所选形态拒绝；UI 防护与服务判权都有效；不以某一形态测试替代其它形态 | C3/C4；平台专用测试，未选形态标未验证 |
| AC17 版本与迁移 | 新旧 UI/服务、未知安全字段、迁移失败/断电、回滚到不识别新 schema 的版本 | 不兼容禁写；旧配置可恢复；版本组合可查；grant/句柄不迁移；恢复后重新诊断 | I01/I14；真实安装器/存储断点证据 |
| AC18 日志与审计 | 合成秘密、导出无权限、留存到期、审计存储失败 | 权限与脱敏生效；负载不能改审计；异常清楚；按确定的审计失败策略处理 | I13；磁盘/导出文件核查，不用真实秘密 |
| AC19 环境删除/卸载 | 有运行会话、有残留资源、选择保留/删除配置 | 先清理并明确残留；环境配置删除不删工作区；不任意递归删路径 | I05/I12/I14；真实合成目录和归属校验 |

## M1 必须跑通的联合场景

使用选定平台上的真实服务和后端，构造无秘密的临时样例仓库：安装/doctor→保存环境→宿主 Agent 创建会话→读取/补丁/测试→从控制台查看结果→发起窄增量审批→可信用户一次批准→宿主显式提交新请求→取消含后代的长任务→关闭会话→独立检查清理。再执行所有者断连、权限拒绝、未知审批字段、清理失败和升级迁移场景。

界面截图只证明所见画面；mock 只验证呈现逻辑。真实后端 E2E 需同时有 UI/客户端观察、服务审计、实际文件/网络拒绝与进程资源检查。测试与安全角色独立核验，不能由控制台单方面签发安全结论。macOS/Linux/Windows 按实际首发范围分别记录；Windows 上看见跨平台文案不等于三平台通过。
